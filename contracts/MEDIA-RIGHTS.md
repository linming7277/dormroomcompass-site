# Media Rights Contract

Each publishable product image records `sourceType`, `provider`, `sourceUrl`, `rightsStatus`, and `allowedForUse`. The template presents only already-approved records; it does not grant or infer media rights.

Demo fixtures may be marked `merchantDynamicData.status = "demo"` and use local example images. Production records require `allowedForUse = true`; otherwise the product cannot pass the product-record validation gate.
